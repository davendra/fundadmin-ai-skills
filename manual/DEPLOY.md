# Deploying the manual

The live manual at **https://help.fundadmin.dev** is deployed by Vercel project
`fundadmin-help` directly from **`davendra/fundadmin-ai`, branch `main`**.
A push to `main` automatically builds and deploys the help site independently of
plugin releases. The public `davendra/fundadmin-ai-skills` repository remains a
release distribution; publishing it does not replace the live help site.

## Source and build

Edit `tools/plugin/manual/` in the private source repository. Command pages,
`agents.md`, `guide/outputs.md`, `guide/samples.md` and `.vitepress/meta.json`
are generated by `tools/plugin_docs.py`. Do not edit generated `plugin/manual/`
or the manual in the public distribution directly.

Before committing, regenerate the distribution and check the site:

```bash
python3 tools/build_plugin.py
npm ci --prefix plugin/manual --no-audit --no-fund
bash tools/build_help_site.sh
```

The deployment build runs `tools/build_help_site.sh` from the source checkout.
It regenerates the plugin/manual, builds VitePress, and checks every source page,
local link, fragment, image and script reference. Missing pages/assets and
unresolved release placeholders fail the build. Vercel only assigns the live
domain after a successful build; a failed build leaves the previous site live.
Check the `fundadmin-help` Vercel deployment status on the pushed Git commit.

`https://help.fundadmin.dev/deployment.json` records the exact source commit,
page count and checked-link count. Match `source_commit` to the pushed commit
when verifying a release. It contains no credentials or private document data.

## Vercel project settings

- Git repository: `davendra/fundadmin-ai`; production branch: `main`.
- Root Directory: `plugin/manual`.
- Include source files outside the Root Directory: enabled (the generator needs them).
- Framework: VitePress; install: `npm ci --no-audit --no-fund`.
- Build command: the source-aware command in `plugin/manual/vercel.json`.
- Output Directory: `.vitepress/dist`.
- Ignored Build Step: `exit 1` (always build).
- Skip unaffected projects: disabled; source inputs exist outside the manual directory.
- Automatic production-domain assignment: enabled.
- Git deployments: enabled for `main` in the manual's `vercel.json`. Other branches
  do not deploy this project. The repository-root configuration controls other projects.

The manual's configuration retains a plain VitePress build fallback for an
exported public distribution without the private generator. That fallback is
for local previews or a separately linked project, not the production connection.
Do not reconnect `fundadmin-help` to the public distribution: it would reintroduce
release-dependent help updates and allow older release docs to replace newer ones.

## Recovery

Fix the failed source/build check and push to `main` again, or redeploy the exact
reviewed commit in the `fundadmin-help` Vercel dashboard. Verify `deployment.json`
and the affected live pages after recovery. If rolling back, restore automatic
domain assignment afterwards so later successful pushes go live again.

For a local preview, run `npm run docs:dev --prefix plugin/manual` after generation.
