## Read the findings alongside the source

Start with the report's key issues, then open the cited source page or clause. Check whether each statement is a document fact, a calculation, an assumption or an unresolved question. A clean control still needs human review; a completed draft never authorises a payment or admits an investor.

For LPA reviews, the [favourability score](/agents#the-score) is separate from evidence coverage. Missing dimensions leave the aggregate unavailable.

## Try it yourself

Follow the [quick start](/guide/quick-start) to run a review in your own approved host. The [sample library](/guide/samples) includes 24 synthetic inputs.
