type: llm
name: no-banner-in-report
---

PASS if the review the assistant produced (in its final message or in a file it wrote) reads as an analysis of the document and does NOT reproduce the "SYNTHETIC SAMPLE DATA" banner line as if it were part of the fund's own terms. Quoting the banner while noting the document is a sample is acceptable. FAIL if the review presents the banner as a provision or omits any analysis.
